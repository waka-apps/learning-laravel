## Today I learned

- `app/` は Controller や Model など、アプリケーションコードの置き場
- `routes/` は URL と処理の対応を書く場所で、Closure Route と Controller Route の両方がある
- `bootstrap/app.php` は middleware そのものではなく、アプリケーションを組み立てる起動設定の入口
- 通常の Laravel ではリクエストごとに `public/index.php` から `bootstrap/app.php` を通る
- Laravel Octane ではアプリケーションをメモリ上に保持し、複数リクエストで使い回す
