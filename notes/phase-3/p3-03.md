## Today I learned

- 既存の学習 repo とは分けて、`laravel/` subdirectory に Laravel project を作成できた
- `php artisan --version` で Laravel project 側の artisan が動くことを確認できた
- `php artisan route:list` で route 一覧と、その route 定義がどの file / line にあるかを確認できた
- `routes/web.php` のデフォルト route は `/` を `view('welcome')` に結びつけている
- `php artisan serve` で最小構成の Laravel app を起動できた

## Differences from Go / TypeScript

- Gin で server を立てる感覚に近いが、Laravel は framework が生成した project 構造と CLI の上で動く
- Next.js のように framework が最初から project 構成を持つ点は近いが、route 定義の見え方は Laravel の方が明示的
