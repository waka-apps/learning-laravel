Lesson: P2-03 - enumでstatusを表現する

## Today I learned

- `enum` を使うと、status に取りうる値を型として制限できる
- `case` は enum の中の具体的な値を表す
- `ShipmentStatus::InTransit` は、`ShipmentStatus` enum の `InTransit` という値
- class の property を `string` ではなく enum 型にすると、不正な文字列を入りにくくできる
- `status()` は内部値を返し、`statusLabel()` は表示用ラベルを返すので役割が違う
- `match ($this->status)` の比較対象を enum にすると、状態分岐を安全に書きやすい

## Still unclear

## Differences from Go / TypeScript

- TypeScript の union 型に近い安心感があるが、PHP はランタイムでも enum の値として扱われる
- Go では定数の組み合わせで表すことが多いが、PHP enum の方が「この型のこの値」と読みやすい
