Lesson: P3-05 - Closure Route から Controller Route へ

## Today I learned

- `php artisan make:controller WelcomeController` で `app/Http/Controllers/WelcomeController.php` を生成できる
- Controller の public method を route の処理として指定できる
- `Route::get('/', [WelcomeController::class, 'index']);` は、`GET /` を `WelcomeController` の `index()` method に結びつける
- Controller は `App\Http\Controllers` namespace に属するため、route file では `use App\Http\Controllers\WelcomeController;` が必要になる
- `php artisan route:list` は `GET /` が `WelcomeController@index` に解決されたことを表示する
- Controller から配列を return しても、Laravel は JSON response として返せる

## Differences from Go / TypeScript

- Gin では handler function を router に直接渡すことが多いが、Laravel は Controller class の method を route に指定できる
- Next.js の file-based routing と異なり、Laravel は route file で URL と Controller method の対応を明示する
