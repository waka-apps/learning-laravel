## Today I learned

- `routes/web.php` の Closure Route を直接編集して、返す response を変えられる
- `view('welcome')` は Blade view を使った HTML response を返す
- `return ['message' => 'ok'];` は Laravel が配列を JSON response に変換して返す
- 同じ `GET /` でも、route の return 内容によって response の種類が変わる

- Next.js よりも route 定義と response 生成の対応が単純に見えやすい
