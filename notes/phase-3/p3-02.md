Lesson: P3-02 - `php artisan` と Laravel project の入口

## Today I learned

- `php artisan` は Laravel project の中で使う Laravel 専用 CLI
- `php artisan list` で使える artisan command 一覧を見られる
- `php artisan help migrate` で `migrate` command の使い方を調べられる
- `php artisan migrate` は migration を実行して DB schema を進める
- `laravel new` は project 作成用、`composer run dev` は Composer scripts 実行であり、Laravel 本体 command とは別物

## Still unclear

## Differences from Go / TypeScript

- Go で言うと `artisan` は project 固有の CLI 入口に近い
- `composer run dev` は npm scripts に近く、framework 固有 command ではなく package manager 側の機能
