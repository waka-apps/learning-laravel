## Today I learned

- `Route::get('/shipments/{trackingNumber}', ...)` の `{trackingNumber}` は URL の可変部分を表す Route parameter
- Laravel は Route parameter の値を、Controller method の対応する引数 `$trackingNumber` に渡す
- Controller が受け取った Route parameter を配列で return すると、Laravel は JSON response に変換する
- Route parameter は入力値を受け取る仕組みであり、それだけでは配送番号の形式や存在を確認しない
- `SHP-999` にも response が返ったのは、現在の `show()` が値をそのまま返すだけで、DB 検索や検証をしていないため

## Still unclear

## Differences from Go / TypeScript

- Gin の `c.Param("trackingNumber")` と目的は近いが、Laravel は Controller method の引数に値を渡せる
- Next.js の dynamic segment に近いが、Laravel は route file に URL pattern を明示し、method 引数と対応させる
