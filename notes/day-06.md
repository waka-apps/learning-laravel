## Today I learned

- `class Shipment` のように、データと振る舞いをひとまとまりとして表現できる
- property は object が持つデータ
- constructor は `new` したときの初期化処理
- method は object に生やす振る舞い
- 関数だけでなくクラスにすると、関連する状態と処理をまとめて扱いやすい

- Goのstruct + method にかなり近いが、constructor という専用メソッド名はGoにはない
- TypeScript class に近いが、PHPでは property の型宣言がより素直に見える
