## Today I learned

- PHPDoc はコメントとして型や意図を補足するためのもの
- `@param list<Shipment> $shipments` は「Shipment インスタンスだけが入る list を受け取る」という意味
- `array` 型宣言だけでは、配列の中身や list / map の違いが分からない
- PHP の型宣言は実行時に効くが、PHPDoc は主に人間、IDE、静的解析向け
- 配列の要素型を補足すると、関数の意図が読みやすくなる

- TypeScript の generic に近い補足感があるが、PHPDoc 自体は型システム本体ではない
