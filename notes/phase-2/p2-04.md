Lesson: P2-04 - exception と `null` の使い分け

## Today I learned

- `?Shipment` は「`Shipment` または `null` を返す」という戻り値型
- `findShipment()` は見つからない時に `null` を返す関数として書ける
- `requireShipment()` は見つからない時に exception を投げて処理を止める
- `try` / `catch` を使うと、exception を呼び出し側で受け取って扱える
- 見つからないことが普通にありえるなら `null`、見つからないのが異常なら exception という使い分けになる

## Differences from Go / TypeScript

- TypeScript の `Shipment | null` に近いが、PHP では `?Shipment` と短く書ける
- Go は error を返す設計が多いが、PHP は exception を投げる設計も自然に使われる
