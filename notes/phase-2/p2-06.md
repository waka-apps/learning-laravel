## Today I learned

- Composer は PHP の依存管理と autoload を担うツール
- `composer.json` は依存関係や autoload ルールなどの project 設定を書くファイル
- `autoload.psr-4` で `App\\` を `src/` に対応付けると、namespace から file を解決しやすくなる
- `vendor/autoload.php` は class を全部先読みするのではなく、必要になった時に解決する loader の入口
- その結果、`require_once` を個別に書かなくても `Shipment` や `ShipmentStatus` を使える

## Differences from Go / TypeScript

- npm と似ているが、Composer は autoload の仕組みまで一緒に扱う点が学習上大きい
- `composer.json` は `package.json` に近いが、autoload 設定まで持つので感覚的には `tsconfig` の一部も近い
