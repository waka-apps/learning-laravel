## Today I learned

- `namespace App\Domain\Shipment;` は、この class が `App\Domain\Shipment` という名前空間に属することを表す
- `use App\Domain\Shipment\Shipment;` は、完全修飾名を毎回書かずに `Shipment` と短く使うための import
- `namespace` を使うと、同じ `Shipment` という名前でも別の所属先として共存しやすくなる
- DDD の文脈では、サブドメインごとに自然なクラス名を持たせやすい
- PHP 自体は directory と namespace の一致を強制しないが、実務では合わせることが多い

## Differences from Go / TypeScript

- TypeScript の import に近いが、PHP では `namespace` 自体も class の所属先として強く意識する
- Go は package 名で整理するが、PHP は完全修飾名を直接使う場面がより見えやすい
