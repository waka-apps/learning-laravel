## Today I learned

- 既存の `Shipment` / `ShipmentStatus` / `hello.php` を使って、Phase 2 の内容を1つの課題にまとめられた
- `ShipmentStatus` enum を property 型として使うことで、配送状態を安全に表現できる
- `trackingNumber` は `readonly`、`status` は `private` にすることで、識別子の不変性と状態変更の制御を分けて表現できる
- `deliveredAt` は未配達の間は値がないので `?DateTimeImmutable` が必要になる
- `findShipment` は「見つからないことがありうる」ので `null`、`requireShipment` は「ある前提が崩れた」ので exception を使う

## Differences from Go / TypeScript

- Go では構造体と method で責務を持たせる感覚が近いが、PHP では visibility や nullable property をより細かく使う
- TypeScript よりも runtime で object の状態変更を制御する設計がコード上に強く出る
